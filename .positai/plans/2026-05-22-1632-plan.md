### 2. Convenção de Nomes de Arquivos

Padrão geral:
```
{patogênio}_{vacina/condição}_{organismo(s)}_{tipo_de_dado}.{extensão}
```

**Prefixos de patogênio/condição:**
- `influenza_fluad_` — Vacina influenza (Fluad; TIV+MF59)
- `hepatitisb_engerixb_` — Vacina hepatite B (Engerix-B)
- `ecoli_infection_` — Infecção por *E. coli*
- `saureus_infection_` — Infecção por *S. aureus*
- `burn_` — Queimaduras (humanos)
- `trauma_` — Trauma (humanos e camundongos)
- `all_human_mouse_` — Dados agregados de todas as condições

**Sufixos de tipo de dado:**
- `_metadata` — Metadados de amostras
- `_eset` — ExpressionSet (Bioconductor)
- `_exprs` — Matriz de expressão bruta
- `_log2fc_sample_clean_long` — Log2FC por amostra, formato longo
- `_dge_limma_degs` — Resultados de expressão diferencial (limma)
- `_dge_btm_process_genes` — Genes por módulo BTM, com log2FC
- `_dge_btm_mean_process` — Médias de log2FC por módulo BTM
- `_gsea_btm_results` — Resultados GSEA com BTMs
- `_gsea_hallmarks_results` — Resultados GSEA com Hallmarks MSigDB
- `_gsea_ssGSEA_btms_results` — Resultados ssGSEA com BTMs
- `_samples_btm_correlation_all_timepoints_summary` — Correlação humano-camundongo por BTM
- `_fit_prediction_results` — Saídas do preditor FIT
- `_sharedgenes_Fisher_Jaccard` — Análise de sobreposição de genes

**Extensões:**
- `.rds` — Objeto R serializado
- `.csv` — Tabela CSV
- `.xlsx` — Planilha Excel
- `_long.rds` — Mesmo dado em formato longo (tidy)

### 3. Schemas das Tabelas Principais

#### 3.1 Metadados de amostras (`*_metadata`)

| Coluna | Tipo | Descrição |
|--------|------|-----------|
| `sample_id` | chr | Identificador único de amostra |
| `geo_sample` | chr | Acesso GEO (formato GSMxxxxxx) |
| `subject_id` / `participant_id` | chr | Identificador do participante |
| `organism` | fct | Espécie: `"Human"` ou `"Mouse"` |
| `timepoint` | num / fct | Dias após tratamento (0 = baseline) |
| `treatment` / `condition` | chr | Vacina ou condição experimental |
| `pathogen` | chr | Patógeno alvo |
| `vaccine` / `vaccine_type` | chr | Nome da vacina |
| `tissue` | chr | Tecido de origem (`"PBMC"`, `"Blood"`) |
| `sex` / `gender` | chr | Sexo biológico |
| `age` | num | Idade do participante |
| `strain` | chr | Linhagem (camundongos) |
| `platform_id` | chr | Plataforma de microarray (GPL) |
| `timepoints_bin` | chr | Categoria temporal (`"Day_1"`, `"Day_7"`) |

#### 3.2 Resultados de expressão diferencial (`*_dge_limma_degs`)

| Coluna | Tipo | Descrição |

| `mgi_symbol` | chr | Símbolo de gene de camundongo (MGI) |
