## New file: `example/example_btm_correlation.R`

### Purpose
Annotated, self-contained script that reproduces the key figure: **Spearman correlation of BTM-level transcriptomic responses between human and mouse, across all conditions and timepoints** (manuscript Figure 3).

### Data flow
```
tables/influenza_fluad_human_mouse_dge_limma_degs.rds   ─┐
tables/btm_annotation_genes.csv                          ─┤─► BTM module means ─► Scatter plot
```

### Script outline (annotated)
1. Load packages (`tidyverse`, `here`, `ggplot2`)
2. Source `required.R` for `theme_vaxgo` and `colors`
3. Load DEG results + BTM annotation
4. Compute per-module mean log2FC for human and mouse
5. Pivot to wide (one column per organism) to enable scatter
6. Filter to Day 7 (peak response)
7. Plot: x = Human mean log2FC, y = Mouse mean log2FC, color = BTM immune group
8. Add Spearman r annotation
9. `ggsave()` to `Figures/`

### Why this figure?
It is the central visual argument of the paper: BTM-level responses correlate between species even when gene-level responses do not. Uses only files already in `tables/`, requires no internet, and runs in < 2 minutes.
